# 🍕 Sammitha Restaurant Menu

A modern and interactive **Restaurant Menu Web Application** built using **HTML, CSS, and JavaScript**.

🎯 **Mini Project for Practice & Placement Preparation**

This project was created to practice frontend development concepts by building a real-world restaurant menu application with interactive features and a modern responsive design.

## ✨ Features

* 🔎 **Live Food Search** – Search for dishes instantly.
* 🏷️ **Category Filter** – Filter food items by category.
* 🍕 **Interactive Food Cards** – View food details and prices.
* ❤️ **Favourite System** – Add and manage favourite food items.
* 🛒 **Shopping Cart** – Add items and manage quantities.
* 💰 **Budget Checker** – Check food selections based on your budget.
* 🌙 **Dark Mode** – Switch between light and dark themes.
* ⭐ **Today's Special** – Highlight special food items.
* 📱 **Responsive Design** – Works on desktop, tablet, and mobile.
* 🎀💙 **Pink + Blue Theme** – Modern gradient-based visual design.
